**사이트: https://yechanh4.github.io/elb-spread/** (공개 · 설치 없이 브라우저에서 실행 · 처음 열 때 10–30초)

전세보증금 15억 → 자가 전세 3.8억 차감 → 국고채 2년물(원금 역산) + 할인분 B로 **3개월 콜 스프레드**를 2년에 8번 롤, 4사이클(8년, 32롤).
목적함수 = P(누적 ≥ G). 참고: `IFPK_draft.pdf`(방법론), `결제행사_운용규칙.docx`(R-1..R-6).

## 실행 (호스팅 · 링크 공유)

### GitHub Pages (현재 배포 방식 — 무료, 서버 없음)
멤버는 링크만 열면 됨(설치·로그인 없음). 저장소와 사이트는 **공개**.
- **계산**: 같은 파이썬 코드(core/ app/ data/)를 브라우저 안에서 Pyodide로 실행 (`web/worker.js`, `app/static_api.py`). 처음 열 때 파이썬 엔진 약 20MB를 받느라 10–30초, 이후 Page 1 ~1초 · Page 2 ~15초 · Page 3(2만 경로) ~1초.
- **데이터**: `.github/workflows/pages.yml`이 **평일 18:45 UTC(뉴욕 장중)** 에 `tickers.txt`의 종목(S&P 500 + 나스닥 100 + 옵션 거래 많은 종목, 544개)을 **8갈래로 나눠 동시에** Yahoo/FRED에서 받음(갈래당 ~5분). 매번 **직전 배포본의 전체 데이터(`data/full.sqlite.gz`)에서 시작해 새로 받은 것만 덮어쓰므로**, 일부 종목이나 갈래 전체가 Yahoo에 막혀도 그 종목은 이전 데이터가 유지됨(STALE 표시). 첫 배포는 `seed/market.sqlite`.
- **브라우저는 쓰는 종목만 받음**: 종목마다 `data/t/<티커>.json`(압축 약 25KB)이 따로 있고, 입력한 종목만 그때 받음. 시작 때는 매크로(`core.sqlite`)와 종목 목록(`index.json`)만.
- **스크리너**: 전체 종목의 IV−HV·IV 순위를 데이터 갱신 때 미리 계산해 `index.json`에 넣음 → Page 2 "전체 종목 스크리닝"이 즉시 상위 60개를 보여줌. 계산은 8개 갱신 갈래가 자기 종목만 나눠서 하고(갈래당 1–2분), 마지막 단계는 합치기만 함. 갱신이 실패한 종목과 코드만 바꾼 push는 직전 순위를 재사용.
- **종목 추가**: github.com에서 `tickers.txt`에 한 줄 추가 후 Commit → 그 커밋이 바로 갱신을 돌림(장외면 직전 종가 호가, `off-hours` 표시). 목록에 없는 종목은 "tickers.txt에 없음"으로 안내.
- **한계**: 저변동·저가 종목은 3개월물 상장 행사가가 K1 목표(+1.56σ̂)까지 안 올라가서 구조를 못 만들 수 있음(사유 표시). 장 마감 후 호가는 스프레드가 넓어 유동성 필터에 더 많이 걸림 → 평일 장중 갱신이 기준.
- **공유 링크**: 입력 전체를 압축해 링크에 넣음(`#/<페이지>?z=…`, 서버 저장 없음).
- **수동 갱신**: GitHub 저장소 → Actions → "Build and deploy site" → Run workflow (장중에 누르면 최신 호가). ECOS 국고채 키는 Settings → Secrets → `ECOS_API_KEY`(선택).
- 로컬에서 정적 사이트 확인: `python -m tools.build_site site && python3 -m http.server 8781 --directory site`. 갱신 한 갈래만: `python -m tools.build_site refresh --db s.sqlite --shard 0/8`.
- 처음 한 번만: 저장소 Settings → Pages → Source를 **GitHub Actions**로.

## 2단계에서 나온 발견 (실체인, 2026-10-29 장중)
- **F. 1.56σ̂ 지점에 상장 행사가는 있음.** AMD(현물 $562, ATM IV 56%) 1월물: K1 목표 809.9 → 상장 810, OI 505/842, 다리별 호가 5.7%/7.0%로 유동성 필터 통과.
- **G. 그런데 "가장 좁은 스프레드"는 비용이 프리미엄보다 큼.** 810/820 순 mid $0.47인데, 두 다리 호가를 진입·청산 때 넘으면 왕복 **158%** (기본값 4%). 폭을 넓히면 810/850 34%, 810/900 15%, 810/1000 10%. 최대지급/순비용은 21×→21×→26×→38×로 오히려 좋아짐. 콤보 주문은 다리 호가 안쪽에서 체결되는 게 보통이라 158%는 최악치지만, 4% 가정은 좁은 스프레드에선 크게 낙관적. → 3단계 전에 K2 규칙(최좁음 vs 비용 반영 폭) 결정 필요.
- **H. 실제 월물은 정확히 3개월이 아님.** 60일 초과 첫 월물이 78일(0.214년). K1 공식은 스펙대로 T_opt=0.25 고정, 실제 만기 기준 σ 거리는 `sigma_distance`로 따로 보고.
- **I. 카탈리스트 타이밍 실례**: JPM 실적 추정일 2027-01-14 = 1월물 만기(01-15) 하루 전 → "만기 1개월 전" 규칙 위반 케이스.
- JPM 6월물은 2027-06-17(목, 6/18 준틴스 휴장)로 정확히 잡힘. Yahoo IV와 mid 역산 IV가 1–3%p 차이(금리·배당·일수 관행 차이) — 둘 다 표시.

## 3단계 (Page 1)
실행: `.venv/bin/uvicorn app.main:app --port 8780` → http://localhost:8780 (미리보기 이름 `elb-web`)
- **K2 = 비용 반영 폭** (`core/structure.py`): K1은 스펙 σ 규칙 그대로, K2 후보마다 체인 호가 왕복비용으로 E^p[롤 배수](또는 목표확률) 점수 → 유동성·절단 통과 중 최고. 스펙 최좁음은 구조표에 흐린 행으로 항상 같이 표시.
- 위험표에 청산 기한까지 영업일 카운트다운, 2영업일 이내면 상단 빨간 배너(R-1, 행사대금 표시).
- 시뮬레이션 제외 규칙: Edge ≤ 0, q 검증 실패, 유동성 미달 — 뒤의 둘은 카드에서 "그래도 사용" 체크 시에만 포함.
- 옵션 할인율 = FRED DTB3(미국 3개월), KRW 2y는 데이터 레이어 값(가정값이면 배지).

## 3단계에서 고친 모델 버그 (중요)
- **J. 변동성 견해에 숨은 상승 드리프트**: μ̂ 없을 때 로그평균을 고정하고 분산만 키워서 E[S_T]가 exp(Δσ²T/2)만큼 올라감(σ 0.45→0.625면 연 ~10% 드리프트). callopt-sim에서 이식한 코드라 거기도 같음.
- **K. 로그수익률 틸팅이 변동성 견해를 폭락 견해로 바꿈**: 실체인 q의 로그분산은 폭락 꼬리가 지배(AMD sd(ln R)/√T 98% vs ATM IV 55%, 왜도 −4.2) → exp(λx²)로 분산을 키우면 폭락 꼬리만 커지고 오른쪽 꼬리는 얇아짐(σ̂ 0.8에서 P(S>K1) 6.1%→5.6%). **p를 가격 공간 모멘트(R=S/S₀의 평균·분산)로 바꿈**: E[S] 정확히 유지, 오른쪽 꼬리 증가(→7.3%).
  - 한계: exp(λR²) 틸팅은 로그정규 σ̂만큼 넓어지지 않음(합성 σ 0.35→0.55: P(S>130) 9.5% vs 로그정규 14.3%) — 시장 분포의 모양을 최소로 바꾸는 KL 해의 성질. 견해를 어떤 모멘트로 표현할지는 결정이 필요한 모델 선택.

- **결정 (2026-10-30): 가격 공간 2모멘트 틸팅 유지.** 수정 후 실데이터(AMD σ̂ 67.7% vs IV 54.8%)에서 변동성 견해 기여 +0.31(롤당 기대배수 0.86→1.17), μ̂ 없으면 드리프트 기여 정확히 0.

## 4단계 (Page 2 역최적화)
- 입력: 금리 시나리오 3개(분류 기준 ±50bp, 사이클당 이동 bp, 확률 — B 막대가 입력 즉시 바뀜), 후보 최대 10개(시나리오별 σ̂·μ̂, 확신도), 스크리너, 제약(3–5종목, 섹터당 2, OI·호가폭).
- 후보별: q → 시나리오별 p_s → 혼합 p_mix로 비용 반영 K2. Edge는 시나리오 확률가중 σ̂ 기준.

- 스크리너: (ATM IV − HV 1y) 오름차순 → IV 순위 오름차순. **IV 순위는 proxy** (오늘 IV가 지난 1년 21일 실현변동성 분포의 어디인지 — 무료 데이터엔 IV 이력이 없음).

## 스펙과 다르게 한 부분 (이유 포함)
1. **Python 3.12** (스펙 3.11). 이 맥에 있는 버전. 3.12 전용 문법은 안 씀.
2. **누적값 = 옵션 회수액 합계(세후)**, B 대비 손익이 아님. 원금은 국고채가 따로 지키므로 옵션이 0이 돼도 15억은 돌아오고, 회수액 전부가 대출 상환에 쓸 돈. 그래서 G를 달성한 뒤 다음 사이클에서 잃어도 누적이 G 밑으로 안 떨어짐 → 흡수상태가 "그 사이클 나머지"만인 스펙과 일치. 비교용으로 전액 국고채 대안(ΣB_c(1+r_c)^T)도 출력.
3. **롤 수 8회.** PDF 본문은 "9회로 분할"인데 3개월×9 = 2.25년 > T=2 (본문 자체 제약 ΣT_i ≤ 2 위반) → 오타로 보고 8회.
4. **틸팅 분산 목표 = 시장 분산 × (σ_used/σ_IV)²** (스펙: σ_used²T). 스큐 있는 q는 Var^q > σ_IV²T라서 스펙대로면 σ̂=IV(견해 없음)에도 분포가 바뀜. 이제 견해 없음 ⇔ p=q (테스트). 제약은 평균+2차 모멘트 두 개, 쌍대 Newton(=∇=0 root-finding).
5. **매수영역 경계 노드를 분수로 포함** (Neyman–Pearson 정석). 그리드 노드 하나가 예산의 0.6%라 이분법만으론 binding이 안 맞았음 → 이제 정확히 일치.
6. **정상성 가정**: 매 롤 같은 머니니스(k1,k2)와 같은 상대비용으로 재진입. 미래 금리 변화는 B에만 반영(3개월 옵션 가격에 r 효과는 미미). 환율 고정 — 환위험 차원 없음(모델 밖).
7. **청산 가치 = 만기 내재가치.** R-1대로 2영업일 전에 팔지만 남은 시간가치는 2차 효과로 보고, 청산 슬리피지는 왕복비용 4%에 포함.
8. **세금**: 청산일의 연도에 실현, 연내 손익통산, 이월공제 없음. 세금은 은행에 넣은 돈에서 내고 굴리는 슬리브에선 안 뺌. 대기자금 이자(15.4%)는 미반영.
9. **파산 = 사이클 말 슬리브 < B_c의 5%** (흡수로 대기 중인 경로 제외). 사이클당·한 번이라도·4번 모두 세 가지 출력.
10. **금리 시나리오**: 분류 기준 ±50bp(스펙), 대표값은 사이클마다 ±75bp 이동(편집 가능). 경로마다 8년 전체 한 시나리오. 혼합은 같은 난수로 각 시나리오를 돌려 확률가중 → P_mix = Σπ_s P_s가 정확히 성립.
11. **K1 규칙은 σ̂ 사용**(스펙 문구대로, σ_used 아님). 계약 수는 MC에선 연속, 표에는 정수 n_int도 표시.

## 1단계에서 나온 발견 (스펙 주장 vs 실제 수학)
- **A. "종목을 늘리면 목표확률이 떨어진다"는 조건부로만 참.** 롤당 기대배수 E[M]이 1보다 확실히 낮으면(0.6) 1→3→10→30종목에서 단조 감소. 그런데 E[M]≈0.9이고 f=1이면 1종목은 첫 실패(롤당 ~82%)에 사이클 전체를 잃어서 **3종목이 1종목보다 높음**(10.5%→15.3%), 그 뒤 다시 하락. 테스트 두 개로 양쪽 다 고정. UI는 단정 대신 곡선을 보여줘야 함.
- **B. f는 "목표확률 vs 파산" 트레이드오프가 항상은 아님 (Dubins–Savage).** E[M] > 무위험 성장(유리한 게임)이면 작은 f가 목표확률도 높고 파산도 낮음(f=0.25: 67% vs f=1: 50%) → 트레이드오프 없음. 불리한 게임에서만 f=1(bold play)이 목표확률 최대이고 그때 파산과 맞바꿈. 기본값 f=1.0은 엣지가 양수일 때 최적이 아닐 수 있음.
- **C. 세금 함정.** 12월에 크게 이겨 그해 세금이 확정되고 다음 해 3월에 전부 잃으면(이월공제 없음) 세금 > 회수액 → **원금에서 세금을 내야 함**. "원금은 구조적으로 보장"이 세후로는 깨질 수 있음. 지표 `p_tax_exceeds_proceeds`로 노출. 다만 G에서 흡수하면 한 번 이긴 경로가 바로 대기하므로 기본 설정 합성 예시에선 0%.
- **D. 핀 리스크는 확률은 낮아지고 금액은 커짐.** 1.25/1.30배 예시 대신 "다음 상장 행사가"(폭 $2.5)를 쓰면 롤당 핀 ~1%(32롤 누적 16–31%)지만 행사대금은 프리미엄의 1,000–4,000배(문서 예시 514배).
- **E. σ̂를 올리면 K1이 더 OTM으로 밀려남** (1.56σ̂√T 규칙). 합성 예시에서 σ̂ 0.40→0.56일 때 E[M]은 1.27→2.13으로 오르는데 P(목표)는 19.8%→12.2%로 떨어짐. 확신이 클수록 복권형이 되는 규칙이라는 뜻.
